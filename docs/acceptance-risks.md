# Приймання: відкриті ризики й зовнішні перевірки

Локальні докази не є дозволом на production-реліз. Нижче вказані відповідальні **ролі**; конкретні люди й прийняття ризиків власником ще не підтверджені.

| ID | Стан і доказ | Відповідальна роль / наступна дія |
|---|---|---|
| R-01 | Часові тести у двох JVM-зонах; runtime із tzdata | Оператор: щомісячне оновлення образу, повтор TS-05 |
| R-02 | Порядок блокувань і реальна конкуренція перевірені; full P4 без порушень | Розробник: зберігати перевірки для нових шляхів запису |
| R-03 | Дозволи порожньої вибірки знято; додано негативну фікстуру прямого читання часу | Розробник: архітектурні тести обов'язкові в CI |
| R-04 | Закрито локальними HTTP-тестами актуальних ролей/enablement | Розробник: підтримувати перечитування на кожному запиті |
| R-05 | Відкрито: офісний доступ і proxy rate limit не перевірені | Оператор: перевірити з зовнішньої мережі до релізу |
| R-06 | Шифрування і відновлення перевірені локально; off-host mount і доставка сповіщень не доведені | Оператор: зовнішня копія, окремий ключ, реальна аварійна доставка |
| R-07 | NTP-правило монітора реалізоване; синхронізація production-хостів не перевірена | Оператор: NTP на обох хостах |
| R-08 | P3 cost 12 перевищив поріг; повтор зі спрощеною сіткою та cost 10 пройшов, GET p95 ≤88 мс | Оператор/власник: обрати й перевірити цільову конфігурацію; типовий cost 12 збережений, ризик для неї не закрито |
| R-09 | Частковий TS-26 у вбудованому браузері: HX-01/02/05/10. Цільові браузери, діалоги, 200%, прокручування й решта HX не підтверджені | Розробник/QA: [повний браузерний чекліст](browser-verification.md) перед релізом |
| R-10 | Закрито для перевіреного PostgreSQL 16: btree_gist, exclusion і ролі працюють | Оператор: повторити на цільовій БД |
| R-11 | Серверні припущення підтверджено тестами й контейнерними репетиціями; браузерна частина окрема | Розробник/QA: повтор при оновленні залежностей |
| R-12 | 60 хв P6: сесії стабілізуються на 367–368; 5xx немає. Свіжість after-GC метрики не доведена | Розробник/оператор: повтор із підтвердженими GC на хвилинах 10 і 60; ризик власником не прийнятий |
| R-13 | Один хост лишається точкою відмови; локальний restore 60,77 с | Власник/оператор: підтвердити прийнятий у дизайні ризик та RTO на реальній інфраструктурі |
| R-14 | Конкурентні тести без sleep/карантину, full P4 коректний у 20 повторах | Розробник: розбирати нестабільність, не вимикати тести |
| R-15 | Підказка про видимість назви реалізована | Власник: підтвердити A-07 для працівників |
| R-16 | Прототипи збережено; README містить затвердження власником 01.11.2026 | QA: огляд фактичної реалізації DR-01…DR-11 |
| R-17 | Базовий HTML 50 кімнат перевищив 300 KB; після вилучення посилань у вільних слотах — 250 458 байтів. Окремий P3 cost 10 пройшов | Розробник: зберігати обмеження розміру; результат cost 10 не доводить продуктивність типового cost 12 |
| R-18 | Конфігураційна межа 48 слотів, legacy-інтервали і перекриття перевірені | Розробник: зберігати fail-fast і тестові межі |
| T29-P4 | Відкрито: p95 успішного створення 2624 мс; прямий COMMIT p95 112,596 мс | Оператор/розробник: повтор на цільовому диску; не вимикати fsync чи блокування |
| T30-COVERAGE | 95 ID не мають Java-тегу; значна частина — ручні/зовнішні припущення | Розробник/власник: закрити прогалини або явно погодити належний спосіб приймання; теги не підміняють докази |

## Чекліст запуску

| Перевірка | Фактичний стан |
|---|---|
| Зашифрована копія поза хостом БД | Шифрування підтверджено; фізично окреме сховище — неперевірене |
| Відновлення <2 год на чистому хості | 60,77 с на окремому контейнері того самого хоста; production RTO — неперевірене |
| Аудит після відновлення | Пройдено, нуль рядків |
| Сповіщення | Правила і 180,5 с недоступності БД перевірені; зовнішня доставка — неперевірена |
| NTP | Експортер і правило готові; production NTP — неперевірений |
| TLS/HSTS, закриті app/management порти | Конфігурація описана; зовнішній мережевий тест — неперевірений |
| Лише офіс/VPN | Неперевірено, адреси середовища не задані |
| Секрети, fail-fast, bootstrap | Локальні тести і production container smoke пройдено |
| Заборона DELETE/DDL для застосунку | Перевірено PostgreSQL-тестами |
| Реліз і сумісний відкат | Пройдено на копії 1 019 092 бронювань |
| Журнали ≥14 днів | Вимога в runbook; реальна ротація — неперевірена |
| TS-26 на production-образі | Див. окремий браузерний звіт; неперевірені клітинки не вважаються пройденими |

Q-01…Q-04 реалізовані за прийнятими у дизайні відповідями: локальні облікові записи, чинні припущення про інфраструктуру, без самостійної зміни пароля. Їх підтвердження у **реальному розгортанні** відсутнє; production-адреси й відповідальний оператор користувачем не визначені.
